# InstructionX_UIKit GUI 性能升级验收记录

对应实施计划：`docs/superpowers/plans/2026-11-14-gui-performance-upgrade.md`

## 验收纪律

本记录与执行 TodoList 分开维护。Todo 的 `done` 只表示对应执行步骤已结束；只有本表要求的全部证据齐全并复核通过，才能将该项验收标为 `[通过]`。

状态只允许：

- `[未开始]`：尚未执行。
- `[执行中]`：实现或测量正在进行，尚未形成完整证据。
- `[阻塞]`：缺少必要输入、硬件或前置条件，不得绕过。
- `[失败]`：任一断言、图像、交互、性能或许可检查未通过。
- `[未验证]`：已有局部结果，但规定平台、真实窗口或性能证据未覆盖；不能解释为通过。
- `[通过]`：全部必需证据存在、可复现、与指定 SHA 一致，且没有已知失败项。

禁止：

- 删除失败断言、缩小既有组件范围、降低数据量或修改原始基线来换取通过。
- 用非空截图、控件能实例化、接口能导入代替功能验收。
- 用 `paintGL()`／`benchmark()`／定时器设定值代替实际呈现帧率。
- 用平均 FPS 掩盖 P95／P99 或长任务失败。
- 把 `未验证`、局部回退或功能缺失描述为完成。
- 未经用户确认提交、合并或推送。

## 不可豁免的性能标准

### 4K 复杂场景

- 真实输出和重型视口均为 3840×2160 物理像素，不能降低 DPR、隐藏主要组件、关闭必要视觉效果或减少约定数据。
- 使用固定复杂页面、数据、随机种子、交互轨迹和主题；预热后每轮连续至少 60 秒，至少 5 轮。
- 合格：每轮有效平均实际 FPS ≥60；P95 ≤16.67 ms；P99 ≤33.33 ms；无应用自身 ≥100 ms 长任务。
- 优秀：每轮有效平均实际 FPS ≥90；P95 ≤11.11 ms；P99 ≤16.67 ms；无应用自身 ≥50 ms 长任务。
- 同时报告 P50、最长帧、missed frames 和 UI 长任务。60 Hz 链路不得宣称优秀档。
- 当前状态：`[未验证]`。没有真实数据时不得填写 FPS。

### 窗口操作

- 拖动、四边／四角缩放、最大化／还原、跨屏和形状变化，每种预热后至少 30 秒、至少 5 轮。
- 动态阶段实际平均 FPS ≥60；P95 ≤16.67 ms；P99 ≤33.33 ms；无应用自身 ≥100 ms 长任务。
- 不得出现明显不跟随、连续多帧不响应、假死、黑帧、闪烁、残影、松开后秒级恢复或音频异常。
- 松开后只执行一次最终高清重建；几何、DPR、命中、焦点、tooltip 与输入状态正确。
- 系统 API 与手动回退路径都须达到同一标准。
- 当前状态：`[未验证]`。

### 功能与视觉

- 同一机器、Qt、字体、DPR、窗口尺寸、主题、数据和控件状态下，最终图像逐像素差异必须为 0。
- 公开构造签名、方法、属性、信号、返回值、数据格式、默认值和 QWidget 返回类型保持兼容。
- 所有既有系列和 option 均须正常；新后端能力不足时精确回退，不得静默忽略。
- 默认 `showSymbol=True` 不变。若未来改变，须另经设计批准并建立新基线，不属于本次无视觉变化验收。
- 当前状态：`[未验证]`。

### 资源与音频

- 连续操作期间内存、显存、位图、FBO／RHI／Scene Graph 资源不得无界增长；隐藏和销毁后资源释放。
- 若空白、原生边框、不透明、GL 全关的最小构建仍复现音频暂停，保留系统／驱动独立调查，不能宣称 UIKit 修改必然解决，也不能因此豁免已确认的 UIKit 热点。
- 当前状态：`[未验证]`。
