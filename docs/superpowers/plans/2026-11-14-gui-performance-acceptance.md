## 验收纪律

本记录与执行 TodoList 分开维护。Todo 的 `done` 只表示实施步骤已结束；只有本表要求的全部证据齐全并复核通过，才能将该项标为 `[通过]`。

状态只允许：

- `[未开始]`：尚未执行。
- `[执行中]`：实现或测量正在进行，尚未形成完整证据。
- `[阻塞]`：缺少必要输入、硬件或前置条件，不得绕过。
- `[失败]`：任一断言、图像、交互、性能或许可检查未通过。
- `[未验证]`：已有局部结果，但规定平台、真实窗口、时长或最终 SHA 未覆盖，不能解释为通过。
- `[通过]`：全部必需证据存在、可复现、与指定代码一致，且没有已知失败项。

禁止删除失败断言、缩小组件范围、降低数据量或修改原始基线来换取通过；禁止用非空截图、控件能实例化、接口能导入代替功能验收；禁止用 `benchmark()`、定时器设定值或离屏耗时代替实际呈现帧率；禁止用平均 FPS 掩盖 P95／P99 或长任务失败。任何局部通过都不能写成整体完成。

所有者最新调整了视觉门槛：Canvas 与 QPainter 不必逐像素为零，但内容、布局、文字、颜色与交互必须完整，视觉近似且无明显错位、黑帧、缺失或伪影。既有精确差异计数仍保留作追踪，不单独据此判定失败。性能、真实窗口、时长、资源与权限要求不因此放宽。

## 不可豁免的性能标准

### 4K 复杂场景

- 真实输出和重型视口均为 3840×2160 物理像素，不能降低 DPR、隐藏主要组件、关闭必要效果或减少约定数据。
- 固定复杂页面、数据、随机种子、交互轨迹和主题；预热后每轮至少 60 秒、至少 5 轮。
- 每轮平均实际 FPS≥60、P95≤16.67ms、P99≤33.33ms，且无应用自身≥100ms 长任务。
- 同时保留 P50、最长帧、missed frames、UI 长任务、环境、源码 SHA 与原始 JSON／CSV。60Hz 链路不得宣称 90 FPS 优秀档。
- 当前状态：`[失败]`。当前直接 Canvas 真实 4K 短测约 53.69 FPS、P95 约 30.67ms，平均 FPS 与 P95 未通过；正式 5×60 秒尚未执行。默认快照后端的旧五轮失败不得冒充当前候选数据。

### 窗口操作

- 拖动、四边／四角缩放、最大化／还原、跨屏和形状变化，每种预热后至少 30 秒、至少 5 轮。
- 动态阶段实际平均 FPS≥60、P95≤16.67ms、P99≤33.33ms，且无应用自身≥100ms 长任务。
- 不得出现明显不跟随、连续多帧不响应、假死、黑帧、闪烁、残影、松开后秒级恢复或音频异常。
- 系统 API 与手动回退路径都须达到同一标准；程序几何测量不能替代原生鼠标验收。
- 当前状态：`[未验证]`。窗口单元手势和回退脚本已通过；普通交互探针已解决前台／原生指针限制，但当前源码的完整原生窗口、时长与帧率证据尚未完成。

### 功能与视觉

- 默认 QWidget／QPainter 基线仍要求同机器、Qt、字体、DPR、尺寸、主题、数据和控件状态下逐像素零差异。所有者已明确：直接 Canvas 采用视觉近似验收，要求内容、布局、文字、颜色和交互完整，无明显错位、黑帧、缺失或伪影，不因不同光栅化器的单纯像素差异直接失败。
- 公开构造签名、方法、属性、信号、返回值、数据格式、默认值和 QWidget 返回类型保持兼容。
- 动态验收冻结动画到指定进度或稳定完成态，不能把自然抖动误判为回归；默认 `showSymbol=True` 不变。
- `tests/perf/compare_visual_baseline.py` 已用同一冻结流程比较原始 `949b728` 与 `de3fc6b` 的亮暗各 80 页，`visual-ab/final-timers/result/comparison.json` 为 160/160 零差异。
- 当前运行逻辑的 `tests/test_visual_compat.py` 已完成 160 个页面状态 RGBA 零差异；历史真实透明弹窗亮暗 16 状态零差异证据保留，不以 DWM 与 QPainter 的合成差异冒充视觉回归。
- 直接 Canvas 的精确差异计数保留于 `temp/performance/59e76d1/visual-canvas-exact.json`，但不再单独作为失败条件。当前真实全屏图 `temp/canvas_widget_current.png` 内容完整，无黑底或明显错位。
- 当前状态：`[通过]`。默认公共视觉兼容通过，直接 Canvas 按所有者最新视觉近似口径通过；最终 SHA 复验仍需在所有者认可后执行。

### 资源与音频

- 连续操作期间内存、显存、位图、RHI／Scene Graph 资源不得无界增长；隐藏和销毁后资源释放。
- 默认 `RhiTextureItem` 最多保留三帧引用，清空使用透明纹理，旧 OpenGL 管线已删除。`ownsTexture=False` 时对超龄纹理显式 `deleteLater()`，销毁时清理剩余纹理。
- 直接 Canvas 不再创建 QQuickWindow 或旧宿主，销毁与弱引用回归通过；长期资源仍需真实测量。
- 4×30 秒复杂场景音频探针历史记录为 `ActiveState / NoError`，不能代替更长时间运行或主观听感验收。

## 回退与停止条件

- 软件 QWidget 视口只用于 offscreen／minimal 或 RHI 初始化失败，复用同一绘制体；不是恢复旧 OpenGL 后端。
- 真实窗口默认使用直接 Canvas；显式 `rhi` 保留完整快照回退。不得用降低负载、隐藏内容或放宽性能红线换取通过；Canvas 的视觉近似豁免不等于性能豁免。
- 原始 `949b728` 仅作为 A/B 和版本回退参考。是否回退、合并或发布由所有者决定，不自动执行。
- 只有 P0–P3 与 T00–T24 全部标为 `[通过]`，且最终 `uniform_style` SHA 上重新验收通过，Goal 才可完成。任何 `[失败]`、`[阻塞]` 或必要场景 `[未验证]` 都不能把整体描述为完成。
