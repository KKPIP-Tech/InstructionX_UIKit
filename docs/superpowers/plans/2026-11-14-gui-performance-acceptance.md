## 验收纪律

本记录与执行 TodoList 分开维护。Todo 的 `done` 只表示实施步骤已结束；只有本表要求的全部证据齐全并复核通过，才能将该项标为 `[通过]`。

状态只允许：

- `[未开始]`：尚未执行。
- `[执行中]`：实现或测量正在进行，尚未形成完整证据。
- `[阻塞]`：缺少必要输入、硬件或前置条件，不得绕过。
- `[失败]`：任一断言、图像、交互、性能或许可检查未通过。
- `[未验证]`：已有局部结果，但规定平台、真实窗口、时长或最终 SHA 未覆盖，不能解释为通过。
- `[通过]`：全部必需证据存在、可复现、与指定代码一致，且没有已知失败项。

禁止删除失败断言、缩小组件范围、降低数据量或修改原始基线来换取通过；禁止用非空截图、控件能实例化、接口能导入代替功能验收；禁止用 `benchmark()`、定时器设定值或离屏耗时代替实际呈现帧率；禁止用平均 FPS 掩盖 P95／P99 或长任务失败。任何局部通过都不能写成整体完成。

## 当前未通过的硬性问题

1. **4K 性能失败。** 当前测量代码在 3840×2160 物理像素、DPR 1.5、八个 2 万点系列下完成正式 5×60 秒测量：`chart_left` 为 1.228–1.676 FPS、`chart_right` 为 0.729–1.122 FPS、Blueprint 为 0.920–1.357 FPS，五轮均未通过，并存在大量超过 100ms 的 UI 长任务。原始数据见 `temp/performance/5c58fdf6933b85d5e4996e83a82c294c0a268e69/realtime/formal/summary.json`。瓶颈是普通实线 `RoundJoin` 与整帧 QPainter 光栅化，不是纹理上传。
2. **不能用画质换性能。** 原生几何、渐变描边、笔型和关闭抗锯齿均有像素差异。后续同进程分段、共享内存多进程、Python 线程和圆角补片也未同时满足零像素与帧预算；`simplified()` 更慢且有 14,033 个差异像素。上述方案均未接入正式后端。
3. **原生窗口验收未闭环。** 自有前台 Qt 窗口中的真实移动、按下与释放已验证；客户区八方向与双击最大化的功能短测通过，系统跨屏完成 5×30 秒、每轮 120 次往返。当前后续预检因测试窗口无法取得前台而阻塞，完整手势、最大化、跨屏和帧率长测不能据此标为通过。
4. **PresentMon 无数据。** `tests/perf/check_presentmon.py` 返回退出码 6：需要管理员权限或 `Performance Log Users` 用户组。未提权、未伪造外部呈现数据；它与前台窗口权限是两个独立问题。
5. **最终验收不能通过。** 当前源码 55/55 独立脚本通过，历史视觉与真实弹窗证据保留；但当前 4K 正式测量失败，完整原生窗口、长期资源和 PresentMon 未满足，最终视觉基线也需在所有者认可的最终 SHA 上复验。

## 不可豁免的性能标准

### 4K 复杂场景

- 真实输出和重型视口均为 3840×2160 物理像素，不能降低 DPR、隐藏主要组件、关闭必要效果或减少约定数据。
- 固定复杂页面、数据、随机种子、交互轨迹和主题；预热后每轮至少 60 秒、至少 5 轮。
- 每轮平均实际 FPS≥60、P95≤16.67ms、P99≤33.33ms，且无应用自身≥100ms 长任务。
- 同时保留 P50、最长帧、missed frames、UI 长任务、环境、源码 SHA 与原始 JSON／CSV。60Hz 链路不得宣称 90 FPS 优秀档。
- 当前状态：`[失败]`。`5c58fdf` 已完成正式 5×60 秒测量，五轮均未通过；原始 JSON 保留全部指标与长任务。

### 窗口操作

- 拖动、四边／四角缩放、最大化／还原、跨屏和形状变化，每种预热后至少 30 秒、至少 5 轮。
- 动态阶段实际平均 FPS≥60、P95≤16.67ms、P99≤33.33ms，且无应用自身≥100ms 长任务。
- 不得出现明显不跟随、连续多帧不响应、假死、黑帧、闪烁、残影、松开后秒级恢复或音频异常。
- 系统 API 与手动回退路径都须达到同一标准；程序几何测量不能替代原生鼠标验收。
- 当前状态：`[阻塞]`。原生移动、客户区边框与双击最大化功能短测已通过，系统跨屏 5×30 秒功能长测通过；当前前台权限阻塞其余长测，且没有完整帧率证据。

### 功能与视觉

- 同一机器、Qt、字体、DPR、尺寸、主题、数据和控件状态下，最终图像逐像素差异必须为 0。
- 公开构造签名、方法、属性、信号、返回值、数据格式、默认值和 QWidget 返回类型保持兼容。
- 动态验收冻结动画到指定进度或稳定完成态，不能把自然抖动误判为回归；默认 `showSymbol=True` 不变。
- `tests/perf/compare_visual_baseline.py` 已用同一冻结流程比较原始 `949b728` 与 `de3fc6b` 的亮暗各 80 页，`visual-ab/final-timers/result/comparison.json` 为 160/160 零差异。
- 当前测量代码的 `tests/test_visual_compat.py` 已通过；历史真实透明弹窗亮暗 16 状态零像素差异证据保留，不以 DWM 与 QPainter 的合成差异冒充视觉回归。
- 当前状态：`[未验证]`。历史基线证据完整，但最终 SHA 的原始视觉与真实弹窗复验尚未完成；这不改变 4K 性能失败与原生窗口阻塞的结论。

### 资源与音频

- 连续操作期间内存、显存、位图、RHI／Scene Graph 资源不得无界增长；隐藏和销毁后资源释放。
- `RhiTextureItem` 最多保留三帧引用，清空使用透明纹理，旧 OpenGL 管线已删除。曾发现 `ownsTexture=False` 下旧纹理没有显式释放的问题；当前实现已对超龄纹理调用 `deleteLater()`，并在销毁时清理剩余纹理。资源复验以当前 HEAD 的正式测量为准。
- 4×30 秒复杂场景音频探针记录为 `ActiveState / NoError`，不能代替更长时间运行或主观听感验收。
- 当前状态：`[未验证]`。
